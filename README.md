# Farmàcia Martí — prototip web

Prototip estàtic en català per a Farmàcia Martí, pensat per publicar amb GitHub Pages.

## Contingut

- Portada inspirada en l’oferta pública de Farmàcia Martí: cura facial, corporal i capil·lar, marques i consulta personalitzada.
- Secció Espais de Salut: Pell, Família, Nutrició i Mascotes.
- Formulari de demostració local; no transmet ni desa les dades introduïdes.

## Provar-ho localment

Obre `index.html` al navegador. No cal instal·lar dependències ni compilar.

## Publicar a GitHub Pages

1. Crea un repositori GitHub buit i puja aquests fitxers a la branca `main`.
2. A **Settings → Pages**, tria **Deploy from a branch**.
3. Selecciona la branca `main` i la carpeta `/ (root)`, i desa.
4. Quan GitHub indiqui que la publicació ha acabat, obre l’adreça Pages del repositori.

Els enllaços a imatges i tipografies són externs. Per a una publicació estable es recomana descarregar o substituir els recursos pels actius autoritzats de la farmàcia.

## Abast del prototip

GitHub Pages només serveix els fitxers estàtics. Les reserves reals, comptes, seguiments i recordatoris necessitaran un servei backend. El contingut i els serveis dels quatre nous espais són una proposta pendent de validació per part de la farmàcia.
